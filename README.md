# Sistem Informasi Akademik Sederhana

Proyek UAS Pemrograman Internet — Sistem Informasi Akademik sederhana berbasis PHP Native (tanpa framework), MySQL, dan Bootstrap 5.

Status: **Dalam pengembangan** 🚧

Dokumentasi lengkap (instalasi, ERD, use case, flowchart, akun default, dsb.) akan ditambahkan pada tahap akhir pengembangan.

## Teknologi

- Backend: PHP Native + PDO
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Database: MySQL (XAMPP)

- Admin
